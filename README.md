## 它是什么

屏幕顶部中间有一座黑色的小岛，里面住着一只三眼小怪——"岛"上的"蛋鬼"，所以叫**岛蛋鬼**（英文 Isle Imp：Isle = 岛，Imp = 调皮的小精怪）。

它是一个 **Windows 桌面智能体**：不需要软件提供接口，屏幕上看得到的软件它就能用——看懂界面、点按钮、打字、切换窗口，像人一样把事情做完。

## 三步上手

| | | |

| 从屏幕顶部的灵动岛，把小怪拖到要用的软件上。它坐在窗口上沿，跟着窗口走。 | 点一下小怪，输入条展开。像发消息一样，把要做的事打出来。 | 它拆解任务、看懂界面，一步步点、输入、发送，做完告诉你结果。 |

不想拖？在任意窗口按 **Ctrl + Alt + G**，小怪直接跳过来并打开输入条。

## 它能做什么

- **会判断，不只会执行**：交给它一份报销单，它会对照标准、核对日期、比对发票号，把有问题的地方逐条标出来并写清原因。
- **一句话，拆成多步**：先列计划再动手，每一步做到哪儿，鼠标移到小怪身上就能看到。
- **看懂界面，不靠接口**：微信、钉钉、WPS、Office、浏览器、邮件、文件资源管理器……大多数 Windows 软件都能操作。
- **跨应用接力**：在 WPS 里查出问题，再到微信里把清单发给财务群，一句话串起两个软件。
- **记得上下文**：对话跟着窗口走，小怪回到同一个窗口，之前聊过的内容还在，接着说就行。
- **不只是点界面**：还能查文件、整理文件夹、上网查资料、回答问题；也支持接入 MCP 工具扩展能力。

## 安全，由你说了算

- 默认**只操作小怪所在的那个软件**；需要动别的软件、执行命令或读写文件时，会先弹出提示等你点"允许"。
- 删除、格式化、关机、改注册表等高风险操作，**无论怎么设置都会单独确认**。
- 你在用鼠标键盘时它会先等你停手，操作完把光标放回原处；想让它停，右键小怪 → 停止任务。
- 紧急情况按 **Ctrl + Alt + Shift + Q** 立即退出。

## 安装

1. 点上面的下载按钮，或到 [Releases](https://github.com/o381/isle-imp-download/releases/latest) 下载 `IsleImp-Setup-1.0.0.exe`。
2. 双击运行 → 选安装位置 → 立即安装。不需要管理员权限，装好后开始菜单和桌面都有"岛蛋鬼"。
3. 安装包暂时没有数字签名，第一次运行如果提示"Windows 已保护你的电脑"，点 **更多信息 → 仍要运行** 即可。

**系统要求**：Windows 10（1803 及以上）/ Windows 11，64 位。

**更新**：下载新版安装包直接运行即可，设置、Key 和对话记录都会保留。

**卸载**：系统设置 → 应用 → 岛蛋鬼 → 卸载，可以选择是否同时删除设置和对话记录。

## 第一次使用

1. 准备一个大模型的 API Key（例如 [DeepSeek](https://platform.deepseek.com/api_keys)）。
2. 右键任务栏右下角的岛蛋鬼图标 → **设置 → AI 模型**：选服务商，粘贴 Key，点"测试连接"。
3. 建议再到 **设置 → 智能体** 点一次"一键自检"，确认它能在你的电脑上正常操作软件。

**支持的模型**：DeepSeek、通义千问、Kimi、豆包，以及其他兼容 OpenAI 接口的服务。测试连接时会自动列出这个 Key 能用的模型。

> 能看图的模型效果更好：遇到控件不全的软件（部分聊天软件、自绘界面），它需要靠截图来定位。

## 常见问题

**需要联网吗？**
安装不需要；使用时需要能连上你所选的大模型服务。国外服务（如 OpenAI）需要代理，岛蛋鬼会自动使用系统代理设置。

**测试连接没通过？**
它会直接告诉你是哪一步出了问题。最常见的是 Key 和服务商不匹配——每家平台的 Key 不通用。

**管理员身份运行的软件操作不了？**
这是 Windows 的限制。岛蛋鬼会弹窗让你一键以管理员身份重启，或设置为以后总是以管理员身份运行。

**之前的对话在哪里看？**
点输入条右边的 🕘 小按钮，或在空输入框里按 ↑。

## 已知限制

- 游戏和部分自绘界面无法读取控件，只能靠截图操作，准确度会低一些。
- Windows 屏幕没有物理刘海，岛蛋鬼会在主显示器顶部中央画一个"小岛"。
- 执行命令、读写文件的能力很强，请只在自己的电脑上使用，并保持默认的"先问我"。
